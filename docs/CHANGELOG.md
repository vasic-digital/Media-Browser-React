# Changelog — @vasic-digital/media-browser

## [0.1.0] — 2026-02-21

### Added
- `EntityBrowser`: top-level browser with search, type selection, and entity grid
- `EntityGrid`: responsive grid with loading and empty states
- `EntityCard`: entity card with title, year, type, rating, description
- `TypeSelector`: type filter buttons
- `Pagination`: prev/next page controls
